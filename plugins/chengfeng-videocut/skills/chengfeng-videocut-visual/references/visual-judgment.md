# 画面判断

真相优先级：**画面正在放什么 > 文字听起来像什么**。

按文字判断会犯这种错：他说「Codex 调用 Grok 做成日报」，听着像讲机制该配动画——
而画面上正放着那份真日报，「来源覆盖」一行里就写着 Grok。盖上去等于用抽象画
替换掉真实证据。反过来，文字听着像该标注（他说「你看这就是结果」），画面却在
段中从输入框切到结果页 —— 固定坐标的圈前半段会指着空白。**两步都做才拦得住。**

## 标注

```text
圈什么       他那句话的证据本身（那行字、那条推文、那个输入框、那串时间戳）
出现时机     说到对应关键词；页面还在滚动就推迟到停稳（量出来的时刻）
静止段提前   素材长时间零变化的段落（量出来 8 帧不动那种），观众会以为播放器卡了
             —— 圈提前出场，成为静止画面里唯一的动态。素材静止也是画面事实
退场时机     画面开始被操作之前 0.2s 退完 —— 圈悬在动了的内容上是最刺眼的穿帮
白底页面     只画框，不压暗。实测能被压暗的内容只占 1.6%，压完整页变灰，上下文全毁
标签         能不加就不加。推近后字能读，框自己会说话
```

## 动画

```text
什么时候     画面停在无关页（图库、空白首页）、或纯概念没有画面可看
风格        从注册表选（当前 xiaohei），先读它的 SKILL 和三份 references
小黑        必须出场并完成核心动作 —— 拿掉小黑意思不变就重新设计
节奏        一个动作讲一件事；2 秒的段只做一个动作
批注        蓝色短句最多 3-5 条，分阶段出现，不一次全亮
```

## 不动

画面自己在讲故事（他正在演示、页面切换本身就是叙事、总结段落画面是实证）时，
加任何东西都是减分。实测 13 段里 4 段的正确答案就是不动。
