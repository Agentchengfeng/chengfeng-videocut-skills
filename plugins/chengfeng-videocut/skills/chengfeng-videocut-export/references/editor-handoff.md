# 目标剪辑器交付

仅在用户要求把成片导入剪辑器、交付原生工程或在目标软件继续剪时读取。这里的导入是目标剪辑器接收已导出媒体，不是创建第二个 Product 项目、素材库业务或上游转录流程。

## 交付类型与授权

| 用户要什么 | 必须交付 | 不代表 |
| --- | --- | --- |
| MP4 文件 | 明确版本、稳定路径和验收等级的成片 | 已进入目标软件 |
| 导入 MP4 继续剪 | 指定软件中的新草稿，成片在时间线上且已保存 | 烧录字幕、HTML 动画成为独立图层 |
| 原生可编辑工程 | 目标版本能打开的草稿与媒体，并验证所承诺图层的可编辑性 | 仅换扩展名或把单个 MP4 放进草稿 |

用户已明确确认「导入这个 MP4」即可执行正常导入，不因没有原生工程转换器重复询问。用户明确要求原生工程时，能力缺失必须说明并请求是否接受替代，不能静默降级。仅导出文件不授权打开/写入剪辑器；导入也不授权删片、变速或发布到平台。

用户接管剪辑器或撤回操控授权后，立即停止剩余操作；不能为了完成下面的保存、重开或验收步骤继续点击。用已有证据报告停在哪一层，再处理仍在授权范围内的事项。

## 选择接入方式

1. 核对实际安装的软件、操作系统与目标版本。优先本机已验证的接口/CLI，或明确支持该平台和版本的草稿库；GitHub 名字相似、README 声称支持或能生成 JSON，不等于本机可直接导入。读取可信来源、版本兼容、依赖和许可；不为导入任务自动更换产品或采用收费/云端上传服务。
2. 没有适用程序接口时，用用户电脑上目标软件的正常导入 UI 完成交付。不要把「无法创建原生多轨工程」当成「不能导入 MP4」。缺少交互权限或必须由用户处理的登录/授权时，停在具体步骤，保留已经完成的结果。
3. 使用库生成草稿时，先在隔离位置验证格式、媒体引用、时长与轨道非空，再按其已支持流程安装到目标软件；不逆向读取加密草稿，不猜存储路径、不手改未知现有草稿。所有方式都要实际打开后验收，文件存在或库返回成功不算导入成功。

## 复用同一份成片

- 先读回既有导出回执及真实文件身份，核对用户选定版本、绝对路径、尺寸/时长/音轨与实际验收等级。只有结构验收时保留视觉、听感 UNVERIFIED，不把它升级为全验收；这不妨碍继续执行已授权导入及目标软件验收。
- 同一版本已经生成且未变更时直接复用，不因交付目的改成「导入」就重新编码。输入版本改变或文件缺失/身份不符时，先说明差异；需要新生成才重新走主 Skill 的计划、确认、snapshot 与 durable job 门禁。
- 绑定正式、稳定的媒体路径，不能引用即将删除的临时目录。若需复制素材，放入新的交付目录并核对身份；保存后确认草稿引用的是该文件。原片、旧 MP4、旧草稿均不覆盖。

## 导入、保存与验收

默认创建唯一命名的新草稿，不向未知用户现有草稿插入。用户指定现有草稿时先核对精确目标和已有状态，保护其未保存修改。实际界面识别元素，不把历史屏幕坐标当固定导入方法。

按顺序分别确认：

1. **素材已导入**：目标素材区出现正确版本，路径绑定正确，没有缺失/离线媒体。
2. **时间线已建立**：MP4 从时间线 0 开始，画幅、总时长和音频与交付计划一致，无意外裁切、静音、重复片段或空轨。只在素材区可见还不算上时间线。
3. **已保存并回读**：保存或等待自动保存完成，读回草稿名称与可用位置；退出该草稿再重新打开同一份，确认时间线和媒体引用仍在。无法完成重开检查时明确标注该项未验证。
4. **目标软件预览**：最少播放或 seek 首、中、尾，检查实际导入成片的画面、字幕、末尾完整性；按风险另查切点和画幅。目标软件预览可作为导入验收证据，但不是 Product 返回的成片抽帧，不能改写原导出的 `visual frame` 结论。音轨存在、波形可见或自动播放都不等于人耳 PASS。

报告文件生成、导入素材、时间线、保存/重开、画面检查与人耳听感各自状态；不要用一项成功概括整条交付。返回实际草稿名称及稳定 MP4 路径，而不是只给「请自行导入」的步骤。

## 已授权的目标软件二剪

只有用户明确要求删静音、变速等二剪时才执行，保留原 MP4，在约定范围内修改新草稿、保存、另导出新文件并复核；不回写 Product 账本，也不把「导入」自动扩成内容重剪。

- 删静音先结合原声、波形和切点判断，检查切点前后是否截断字词；不以黑屏代表无声，不批量吞掉语义停顿。视频与音频联动删除，烧录字幕跟随同一画面，避免声画错位。
- 变速使用已约定倍率，确认视频和声音同步，保留正常音高的设置未意外关闭；预期时长按「删除后的总长 ÷ 倍率」核对，允许与输出帧率相符的舍入差。
- 另导出前确认目标文件不存在；完成后回读真实输出的尺寸、时长、音轨并检查首中尾及改动切点。试听与结构检查仍分开报告，没有人实际听过一律记 `human listening UNVERIFIED`。
